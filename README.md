## 📖 Aide-Mémoire commandes Git dans le terminal :
>💡(Assurez-vous d'être dans le dossier du projet avant d'utiliser les commandes)
- 🔄 **Mettre à jour la branche actuelle en local:**
  - `git pull`: récupérer et appliquer les changements depuis GitHub

- 🌱 **Gérer les branches**
  - `git branch`: voir toutes les branches locales ( le * montre la branche active) 
  - `git checkout -b nomdelabranche`: créer une nouvelle branche et s'y déplacer
  - `git checkout nomdelabranche`: se déplacer sur une autre branche
    
- 🚀 **Enregistrer et ajouter son travail sur GitHub:**
  - `git add .` ➡️ `git commit -m "Description claire de la modification"` ➡️ `git push origin nomdelabranche` : add + commit (local) puis publier la branche sur GitHub

  - 🪄 **Concernant les pull requests:**
    - `Base`: la branche qui va recevoir les changements
    - `compare`: La branche qui contient le changement
    Donc, base devenir une copie de compare 
- **Autres commandes utiles:**
  - `git status`: Voir l’état des fichiers et de la branche
  - `git log`: Voir l'historique des commits
